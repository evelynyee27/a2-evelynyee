## my notes

This is a to-list/note app where you can add tasks or messages to be completed. I used a CSS flexbox to display each element side by side.

## Technical Achievements

- **Tech Achievement 1**: I created a single-page app that provides a form for users to submit notes, and the server updates the table of data after submission. The form also allows deletion of data.
